## What eva-md is

Hooks in Codex and Claude Code record each chat into a local inbox, secrets removed. A chat's start gets a brief labelled eva.md; a prompt may get a saved statement or a pointer to a system's page. After a chat, a background job runs the host's model headless to organize it into a wiki of thread, rules, knowledge and system pages, a git repository pushed daily; a daily sweep takes idle chats.

## Where things are

- The program: `~/.local/share/eva-md/bin/eva-md`, maybe on PATH as `eva-md`; its modification time is the upgrade's. Config: `~/.config/eva-md/config.toml`; it names the wiki folder.
- State, `~/.local/state/eva-md/`:
  - `inbox/<project>/<host>-<session>.jsonl`, a file per session; fields include `turn`, `role`, `kind`, `agent`, `origin` (`hook` or `catchup`), `cwd`, `red` (redactions), `text`. Print none of `session`, `project`, `branch`, `model`, `cwd`, `text`: compare them in a script.
  - `updates/<date>.jsonl`: the background job's run log, a file a day, never pruned. New: `trigger` (absent in older records), `rejection` (`rule`, `place`), `model_reported` (Claude Code only); busy exits in `updates/busy-<date>.jsonl` (outcome `busy`, no host, `trigger`, `session_hashes`). Print none of `session`, `project`, `thread`, `session_hashes`, `model`, `model_reported`, `model_note`, `degraded`.
  - `heartbeats/<host>/<event>.json`: per hook event, the last 20 `runs` and, new, `week`: up to 7 UTC `day` entries of counts.
  - `catchup/<host>/<session>.json`: transcript recovery per session: `missing`, `blocked`, `elsewhere`, `reason`, `headless` (a program's chat) and, new, `missing_why`: `none_named`, `refused` (a hook named one and recovery refused it) or `not_written` (absent in older records). Never print its paths, folders or copy of the last entry.
  - `commits/<YYYY-MM>.jsonl`: each daily commit and push: `outcome`, `reason`, `pages`, `push`, `unstaged` (page paths: count only). Also `commit/`, `logs/`, `cache/`, maybe `code-status.json` (slugs, repository keys, paths: count only).
- Not faults by being there: `commit/push-retry`, a timer every check sets; `needs-trust.json`, which install rewrites whenever the Codex plugin changes (a new date means that, not that Codex asked; a hook review is awaited only until a Codex chat start after it).
- Host session files: `~/.codex/sessions/`, `~/.claude/projects/`.
