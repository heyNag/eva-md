# Working papers for the v2 plan

These are the inputs [the plan](../plan.md) was distilled from. They are kept so the evidence behind each decision can be checked, and so the people and agents who build from the plan can read the detail for their area.

**The plan governs.** Where a paper here disagrees with the plan, or two papers disagree with each other, the plan is right and the paper is out of date. Nothing here is a specification.

| Folder | What it holds | How to read it |
| --- | --- | --- |
| `audit/` | 17 audits of eva-md as it stood at commit 51b241c, one per part. Each ends with a "Verification" section in which a second reader tried to refute every finding | The second reader's verdict and severity win. [findings.md](../findings.md) is the merged register |
| `research/` | Six research notes from primary sources as they stood on 2026-11-10. Each ends with a "Fact check" section | Host facts go out of date within weeks. Confirm on a real host before building on one |
| `design/` | Six area designs and three critiques of them | The designs were written in parallel and disagree in places. The plan records how each disagreement was settled |
| `field/` | The check of the owner's note of 2026-11-06 against the code: 44 points, each with what v1 does, what the plan does and a second reader's verdict; and what Codex's source says about its voice mode | The second reader's correction wins over the first reader. Section 14 of the plan is the lead's reading and governs. The note itself and the field report are private and are not in this repository |

The audits and research name files and lines in this repository and in the page library eva-md v1 was built on. Paths are relative to the repository root.
