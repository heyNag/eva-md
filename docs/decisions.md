# eva.md decisions

The decisions behind eva.md are dated records in [decisions/](decisions/), one a file named `<YYYY-MM-DD>-<slug>.md`.
On 2026-11-14 this file was frozen and split, word for word, into them: each of v1's 17 decisions is one record, dated by the first commit that held it, and so is each other part of this file and the design's "Changes to decisions".
A record that the v2 plan reopens says so; a new decision is a new record.

Each record holds these fields, in this order: **Status** (Accepted, or Reopened when a row of the [v2 plan's section 7](v2/plan.md#7-decisions-for-the-owner) reopens it), **Date**, then the sections **Context**, **Decision**, **Consequences**, **Reopens** (the records or rules it changes) and **Reopened by** (the rows of the plan that change it).
