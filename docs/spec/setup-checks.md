- **Config** (`internal/config`).
  Defaults, bounded private reads, unknown keys recorded but never saved back, an explicit `daily_cap = 0`, the `commits` switch, `reminder_every` (its default, an explicit 0, a round trip through a save and the refusal of a negative number), path exclusions through symlinked aliases, remote exclusions written as URLs, in scp form or with `.git`, and the rejection of one that can't be normalized.
  The `recall` switch: true by default, `recall = false` kept through a save, a misspelled key reported as unknown and a string refused (`TestRecallSwitch`).
